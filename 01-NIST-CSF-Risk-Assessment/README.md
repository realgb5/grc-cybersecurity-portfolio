# NIST CSF 2.0 Cybersecurity Risk Assessment

## Overview

A simulated cybersecurity risk assessment for a fictional financial services organization aligned with the NIST Cybersecurity Framework (CSF) 2.0.

## Objectives

- Assess the organization's cybersecurity posture
- Identify gaps between current and target states
- Identify and prioritize cybersecurity risks
- Develop remediation recommendations
- Demonstrate practical GRC and IT Risk skills

## Framework

NIST Cybersecurity Framework (CSF) 2.0

## Deliverables

- NIST CSF 2.0 assessment
- Risk register
- Gap analysis
- Remediation plan
- Executive risk dashboard

> This is a simulated portfolio project. The organization, assessment data, findings, and recommendations are fictional and created for demonstration purposes.
